# Лабораторная работа №2. Вариант 3

«Волк и семеро козлят», родственные процессы, один к одному. Взаимодействие: очереди сообщений
(`mq`), именованные каналы (`fifo`), сокеты (`sock`).

Хост (волк, GUI на Qt) делает `fork()` до создания `QApplication`, ребёнок — козлёнок.
Очерёдность обмена — два семафора `sem_init` в общей анонимной памяти, все ожидания с таймаутом 5 с.
Каналы открываются в каждом процессе уже после `fork()`, файлы fifo и сокета удаляет хост.

## Сборка

```bash
sudo apt install build-essential cmake qtbase5-dev
./build.sh        # собирает host_mq, host_fifo, host_sock и tests/test_game
```

Для каждого `src/conn_<code>.cpp` автоматически собирается `host_<code>`.

## Запуск

```bash
./host_sock                      # GUI: 3 с на ввод числа волка, иначе оно случайное
./host_mq --no-gui --rounds 10   # игра в терминале
```

## Тесты

```bash
./tests/run_tests.sh
```

Правила игры (юнит-тесты), игра по каждому каналу, удаление файлов, таймауты 5 с при зависании
волка или козлёнка, остановка по SIGINT, GUI в режиме offscreen.
